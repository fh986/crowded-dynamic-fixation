# crowded-dynamic-fixation

This folder contains materials and codes for the project "EasyEyes: crowded dynamic fixation for online psychophysics" (doi: https://doi.org/10.1101/2025.02.26.640403).

## easyeyes_materials
This folder contains materials needed for creating the EasyEyes experiment used in the study. One can upload the files to easyeyes.app to compile the experiment.

## easyeyes_handshaking
This folder contains codes and functions needed to record Eyelink data. To record data, install Psychtoolbox and CriticalSpacing, and run easyeyesHandshaking.m.

## data_include_forGaze_20ppl_paired
This folder contains data from the 20 participants included for gaze analysis.

## data_include_threshold_18ppl_paired
This folder contains data from the 18 participants included for threshold analysis. 

## Gaze_package
This folder contains some functions used for data analysis

## analysis_codes
This folder contains codes used to generate all the figures in the paper.
